# Security

There is no supported production release yet. Do not use development builds for
production credentials or unattended production actions.

Report vulnerabilities privately using the repository's GitHub **Report a
vulnerability** facility when enabled. If unavailable, contact the maintainer
privately to establish a reporting channel before sharing technical details.
Do not post credentials or exploitable private details in public issues.
Response time is best effort until a maintained stable release is published.

The threat model and required fixtures are in `docs/spec/10_Security.md`.
