# Milestone 5: bounded specialist crew

Use existing repository observation and policy rather than an agent framework.
CEO makes deterministic delegation decisions. Repository Scientist records real
read-only observations; Test Engineer freezes the targeted command and baseline
identity. These roles perform local work without spending a model call.

A multi-module scope activates a real read-only Architect request with validated
goal, assumptions, expected paths, acceptance, risk and verification output.
Two failed implementation attempts activate one real read-only Debugger request.
Only Implementer can propose edits; policy still authorizes exact actions.

Each delegation records its scope, real lifecycle and artifact. All model roles
share one call/deadline budget and configured routing. Model output cannot expand
paths, change the frozen test command, authorize writes or issue a verdict.

Acceptance: trivial source fixture needs only Implementer inference; multi-module
scope activates Architect; two behavioral failures activate Debugger; untrusted
plans cannot expand scope or weaken acceptance. Run unit/integration checks and
repeat actual Codex/OpenPitStop acceptance. No simulated role activity.
